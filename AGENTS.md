# Repository instructions

## Agent interoperability

For every change to agent instructions, tools, or protocol adapters, check the [AAIF project directory](https://aaif.io/projects) and follow the current upstream specification for each interface this repository implements. Use the AGENTS.md convention for repository guidance. Record the protocol revision and compatibility checks when an interface changes. For changes to example envelopes, identify the protocol revision used by each fixture. Keep examples synthetic and verify schema changes offline.
